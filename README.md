# 🛠️ Настройка ИИ-верстака Agnes Code в один клик

Этот проект предназначен для автоматической настройки искусственного интеллекта в приложении **Agnes Code**. ИИ-агент самостоятельно настраивает окружение в фоновом режиме, оптимизирует потребление памяти и защищает кодовую базу.

---

## 🚀 Как запустить автонастройку

1. **Скачайте проект:** Нажмите кнопку **`Code`** на странице репозитория и выберите **`Download ZIP`**, затем распакуйте архив.
2. **Установите ПО:** Убедитесь, что у вас установлены [Agnes Code](https://agnes-ai.com/agnescode) и [Git](https://git-scm.com).
3. **Откройте проект:** В Agnes Code выберите `File` -> `Open Folder` и укажите папку с распакованным проектом.
4. **Запустите ИИ:** Напишите любое приветствие в чате, чтобы агент применил инструкции и настроил систему.

---

## 💸 Страховка от лишних трат (Лимит токенов)

При работе со своими API-ключами агент может уйти в бесконечную «петлю отладки» и незаметно потратить ваш баланс. Чтобы защитить бюджет, вы можете установить жесткие лимиты в файле настроек (`%APPDATA%\AgnesCode\settings.json` для Windows или `~/.config/agnes-code/settings.json` для Linux/macOS):

```json
"budget": {
  "max_tokens_per_task": 200000,
  "max_tokens_per_session": 500000
}
```

### ❓ Как это выглядит для вас вживую?

1. **Мягкая остановка:** При превышении **200 000 токенов** на задачу ИИ остановит процессы и предупредит вас в чате, предложив сменить подход или продолжить.
2. **Жесткая блокировка:** При достижении лимита в **500 000 токенов** за сессию сработает защитная блокировка чата для сохранения вашего бюджета.

## ⚠️ Подключение сторонних API-ключей

По умолчанию используется бесплатная модель `agnes-3.0-flash`. Для подключения сторонних провайдеров (Claude, OpenAI, DeepSeek) перейдите в **Settings** -> **AI** в Agnes Code, нажмите **`+ Connect`** и введите API-ключ, который шифруется локально.
